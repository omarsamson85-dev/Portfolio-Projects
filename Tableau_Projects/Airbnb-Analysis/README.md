# Airbnb Data Analysis — Tableau Dashboard

## Project Overview

This project is an interactive Tableau analysis of Airbnb listing and calendar data. The dashboard explores pricing, bedroom distribution, geographic price variation, and revenue trends.

## Data Source

The underlying Airbnb data was sourced from Kaggle. The project work combined the **Listings**, **List**, and **Calendar** data into an Excel workbook, which was then used as the working data source in Tableau.

## Dashboard Preview

The completed Tableau dashboard contains:

- **Average Price Per Bedroom** — compares average listing price across bedroom counts.
- **Listing Distribution by Bedroom Count** — shows the number of listings for each bedroom category.
- **Price Per ZIP Code** — maps and compares average prices geographically.
- **Price by ZIP Code** — ranks ZIP codes by average listing price.
- **Revenue for Year** — shows the revenue trend across the calendar year.

## Key Business Questions

1. How does Airbnb pricing vary by number of bedrooms?
2. Which ZIP codes have the highest and lowest average prices?
3. Where are Airbnb listings geographically concentrated?
4. How does revenue change throughout the year?

## Notes on Reproducibility

The Tableau workbook was originally created against a local Excel file path on the author's computer. For full reproducibility, the combined Excel workbook should be kept in the same project folder and the Tableau data connection may need to be repointed to the repository copy when opened on another computer.
