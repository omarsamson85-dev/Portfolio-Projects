Nashville Housing Data Cleaning

This folder contains the source data used for the Nashville Housing SQL data-cleaning project.

Source Data

The project uses the Nashville Housing dataset:

`Nashville Housing Data for Data Cleaning.xlsx`

 SQL Table

The dataset was imported into SQL Server and stored as:

`NationalHousing`

Data Cleaning Tasks

The SQL project demonstrates:

- Date standardization
- Handling missing property addresses
- Populating missing values
- Self-joins
- Data transformation
- Standardizing categorical values
- Removing unwanted data
- Altering table structure
- Preparing data for analysis
